# Retail Sales Performance Analytics Dashboard

## 📌 Project Overview

An end-to-end retail sales analytics project focused on understanding sales performance, profitability, product trends, and regional performance.

The project combines Python-based exploratory data analysis with Power BI dashboard development to transform raw retail data into meaningful business insights.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Jupyter Notebook
- Power BI
- DAX
- Power Query
- Excel
- Statistics

## 🔍 Analysis Performed

### Python / Pandas
- Performed exploratory data analysis
- Examined data distributions
- Identified potential outliers
- Checked data quality
- Analyzed sales, profit, quantity, and discount metrics

### Power Query
- Cleaned and transformed the raw dataset
- Validated data types
- Standardized text values
- Filtered unnecessary columns

### Data Modeling
- Built a star-schema data model
- Created a central Fact Sales table
- Connected Product and Date dimension tables
- Used one-to-many relationships

### DAX & Dashboard
Created measures for:

- Total Sales
- Total Profit
- Profit Margin
- Total Quantity

Built an interactive Power BI dashboard using:

- KPI Cards
- Slicers
- Category analysis
- Regional analysis
- Sales and profit visualizations

## 📊 Project Files

- `Retail_sales_dashboard.pbix` — Power BI dashboard
