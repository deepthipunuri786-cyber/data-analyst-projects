# Sales Data Analysis

## 📌 Project Overview

An Excel-based sales data analysis project focused on evaluating business performance, identifying top-performing regions and customer segments, and understanding monthly sales trends.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Dynamic Charts
- Data Analysis
- Data Visualization

## 🔍 Analysis Performed

- Analyzed sales data to evaluate overall business performance.
- Used Pivot Tables to summarize and explore the data.
- Identified top-performing geographical regions.
- Analyzed customer segments to understand their contribution to sales.
- Visualized monthly sales trends.
- Identified seasonal patterns in sales performance.

## 📊 Key Skills Demonstrated

- Sales Data Analysis
- Pivot Table Analysis
- Data Visualization
- Regional Analysis
- Customer Segmentation
- Trend Analysis
- Business Insights
