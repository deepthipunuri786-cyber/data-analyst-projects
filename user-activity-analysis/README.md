# User Activity Analysis

## 📌 Project Overview

An SQL-based user activity analysis project focused on understanding user login behavior, engagement, and retention patterns.

## 🛠️ Tools & Technologies

- SQL
- Excel
- Window Functions

## 🔍 Analysis Performed

- Analyzed raw user login activity data.
- Calculated Daily Active Users (DAU).
- Used the `LAG()` window function to analyze consecutive login activity.
- Identified user activity and retention patterns.
- Used SQL aggregations and filtering to derive meaningful engagement insights.

## 📊 Key Skills Demonstrated

- SQL Data Analysis
- Window Functions
- User Engagement Analysis
- Retention Analysis
- Aggregations
- Business-Oriented Data Analysis
